# 实施报告模板

> 实施者写全量细节到本文件；回主控只回 6 行摘要。

## 摘要（回给主控）

```
STATUS: DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED
COMMIT: <sha7 或 "no-git，见下方改动文件清单">
TESTS: <一行摘要，如 "12 passed, 0 failed">
CONCERNS: <一句话或 none>
REPORT: <本文件绝对路径>
```

## 任务

- Task: <N>
- Brief: <路径>
- 主张耗时: <可选>

## TDD 证据

### RED（先看见它失败）

```
命令: <测试命令>
输出: <失败输出原文——失败原因必须是功能缺失，不是笔误>
退出码: <非0>
```

### GREEN（最小实现后通过）

```
命令: <测试命令>
输出: <通过输出>
退出码: 0
```

### 变色检查

> 故意改坏实现，测试必须变红；不变红即废测。

```
改动: <改了什么>
结果: <测试变红 / 未变红→说明原因>
```
